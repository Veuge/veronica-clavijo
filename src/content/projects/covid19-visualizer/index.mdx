This is an app that uses the [disease.sh](https://disease.sh/) API to search and select multiple countries to that you want to compare the accumulative number of cases overtime in a linear chart. When selecting a specific one from the footer it displays a counter of total number of cases, deaths and total recovered.

Currently available only in Spanish.
